# 구현 및 검증 계획
빈 저장소에서 Next.js + pg + node-pg-migrate 앱을 구현한다. 서버 세션과 역할별 응답 경계를 우선 구성한다. DB 마이그레이션/도메인과 UI를 독립 구현 후 통합한다. UTC 기록/KST 날짜, 초 단위 계산/일별 원 반올림, 기간 변경 연속성, 트랜잭션 및 멱등성을 테스트한다. 로컬 DB 마이그레이션 up/down/up, 샘플 seed, 빌드/타입/린트/기능 검사, 모바일/데스크톱 실제 캡처와 시각 검수를 수행한다. 연결이 없는 환경은 명시적 샘플 모드로 제공하고 실제 DB 연동 검증과 구분한다.
