# 디자인 근거 (2026-09-13 확인)

- [WCAG 2.2](https://www.w3.org/TR/wcag/): 포커스가 고정 내비게이션에 가려지지 않도록 안전영역/스크롤 여백 적용. 상태를 텍스트와 아이콘으로 함께 표현. 본 앱은 요청대로 최소 44×44px 터치 영역을 목표로 한다.
- [Next.js PWA guide](https://nextjs.org/docs/app/guides/progressive-web-apps): App Router manifest 및 서비스 워커, HTTPS 배포와 홈 화면 설치 지원. 근태 데이터는 오프라인 저장/재전송하지 않는다.
- [Material navigation bar](https://m3.material.io/components/navigation-bar/overview): 모바일의 3~4개 핵심 목적지를 하단에 배치하고 아이콘과 한국어 레이블을 함께 유지한다.

크림 배경, 짙은 초록 주요 작업, 절제된 주황 확인 필요 표시. 시간/금액은 tabular-nums, 모바일 출석부/급여는 카드 중심으로 구성한다. 정보 전달은 실제 HTML 컴포넌트와 벡터 아이콘으로 충분하므로 장식용 생성 이미지는 추가하지 않는다.

## UI 정리 (2026-09-18)

- 화면 순서: 제목 → 핵심 작업/현황 → 기록. 사장님 홈은 수치와 직원 목록, 직원 홈은 근무 상태와 출퇴근 버튼을 우선한다.
- 로그인은 중앙 폼으로 단순화한다. 소개 배너, 장식 시계, 영어 소제목, 사이드바 응원 카드, 반복 소개 문장과 푸터는 제거한다.
- 한국어 시스템 글꼴을 사용하고 외부 글꼴 요청을 없앤다. 본문은 15~16px, 보조 정보는 13~14px, 제목은 24~30px를 기준으로 한다. 입력란은 모바일 확대 방지를 위해 16px 이상을 사용한다.
- 이름·근무시간·금액의 위계를 높이고, 모바일에서도 등록 버튼의 문자를 표시한다. 버튼과 펼치기 영역은 최소 44×44px를 유지한다.
- 필드 제약, 미퇴근/오류 기록 제외, 급여 포함 범위, 변경 이력 안내는 짧게 유지한다. 실제 기록의 사유·감사 내역은 삭제하지 않는다.
- 비교 기준은 기존 캡처와 사용자의 가독성/간결성 요구다. 별도 완성 디자인 이미지와의 픽셀 일치를 의미하지 않는다.
